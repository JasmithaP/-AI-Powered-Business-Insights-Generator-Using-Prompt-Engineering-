# 🧠 AI-Powered Business Insights Generator

This tool uses Generative AI (GPT-4, LangChain, and Prompt Engineering) to automatically generate insights from structured business data.

## 🔑 Features
- Upload CSV datasets and get actionable insights instantly
- Prompt Engineering using Few-shot, CoT, and zero-shot techniques
- Real-time analysis and clean visual interface with Streamlit

## 🚀 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
